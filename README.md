One pickup line (at most 200 characters) in the voice of a robot trying to
charm someone, entered in the
[The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b)
competition on [make.fun](https://make.fun).

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes that line to
`/output/entry.txt`, with no trailing newline, mode 0644, and prints the
same line to stdout.

The line:

> I was built to pass the Turing test, but one smile from you overheated my processors — care to help me cool down over coffee?
